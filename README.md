# MAX Web — GREEN-API Messenger Client

Веб-клиент мессенджера **MAX** на **React**, разработанный в рамках тестового задания для **GREEN-API**.

Интерфейс спроектирован по прототипу веб-версии [web.max.ru](https://web.max.ru/) и реализует отправку и получение текстовых сообщений через шлюз **GREEN-API** с использованием технологии **HTTP API (очередь уведомлений)**.

---

## 🚀 Стек технологий

- **React 19** + **TypeScript**
- **Vite** (сборка и быстрый HMR)
- **Tailwind CSS v4** (адаптивная стилизация, дизайн-система MAX)
- **Lucide React** (иконки интерфейса)
- **Web Audio API** (звуковое оповещение о входящих сообщениях без внешних ассетов)

---

## 📋 Реализованный функционал

1. **Авторизация по учетным данным GREEN-API**:
   - Ввод `idInstance` и `apiTokenInstance`.
   - Возможность указания кастомного `apiUrl` (по умолчанию `https://api.green-api.com`).
   - Автоматическая валидация учетных данных методом `getStateInstance`.
   - Сохранение сессии в `localStorage` с возможностью выхода.

2. **Создание диалогов**:
   - Ввод номера телефона получателя в международном формате (например, `79991234567`).
   - Проверка наличия контакта в MAX методом `checkAccount` с автоматическим получением точного `chatId`.
   - Возможность задать имя собеседника.

3. **Отправка текстовых сообщений**:
   - Реализована методом [`SendMessage`](https://green-api.com/v3/docs/api/sending/SendMessage/).
   - Оптимистичное добавление сообщения в чат с индикатором отправки.
   - Поддержка отправки по клавише `Enter` (перенос строки по `Shift + Enter`).
   - Счетчик символов (до 20 000 символов в соответствии с лимитами MAX API).

4. **Получение входящих сообщений в реальном времени**:
   - Реализовано по [технологии HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/):
     - Фоновый опрос очереди методом `ReceiveNotification` (`receiveTimeout=5`).
     - Обработка типа уведомления `incomingMessageReceived`.
     - Немедленное удаление обработанного уведомления методом `DeleteNotification` для продвижения очереди FIFO.
   - Звуковое уведомление при поступлении входящего сообщения.
   - Счетчик непрочитанных сообщений в списке чатов.
   - Автоматическое создание чата при получении входящего сообщения от нового контакта.

5. **Интерфейс по образцу web.max.ru**:
   - Фирменные цвета MAX (`#0066FF`, оттенки серого, мягкий фон чата).
   - Адаптивная верстка (мобильная версия с переключением экрана и десктопная сплит-панель).
   - Поиск по диалогам и контактам.
   - Индикатор статуса синхронизации HTTP API в реальном времени (🟢 Активна, 🟡 Чтение, 🔴 Ошибка).

## 🛠 Инструкция по локальному запуску

### Требования
- Установленный **Node.js** версии 18+ (проверено на Node.js v22).
- Менеджер пакетов **npm** (или yarn / pnpm).

### Шаги запуска

1. **Клонируйте репозиторий или перейдите в папку с проектом**:
   ```bash
   cd Chat
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Запустите проект в режиме разработки**:
   ```bash
   npm run dev
   ```

4. **Откройте приложение в браузере**:
   Обычно приложение доступно по адресу:
   ```
   http://localhost:5173
   ```

5. **Сборка для продакшена (опционально)**:
   ```bash
   npm run build
   npm run preview
   ```
   Собранные статические файлы будут находиться в папке `dist/`.

## 🧪 Как протестировать работу

1. Откройте [Личный кабинет GREEN-API](https://console.green-api.com).
2. Зарегистрируйтесь и создайте инстанс (на бесплатном тарифе «Разработчик»).
3. Авторизуйте инстанс по QR-коду в мессенджере **MAX** (или WhatsApp).
4. Скопируйте **idInstance** и **apiTokenInstance** из карточки инстанса.
5. В интерфейсе приложения введите эти данные и нажмите **«Подключиться к чату»**.
6. Нажмите кнопку **«+»** (Новый диалог), введите номер телефона собеседника и нажмите **«Начать чат»**.
7. Отправьте текстовое сообщение — получатель получит его в мессенджере.
8. Отправьте ответное сообщение из мессенджера — оно сразу отобразится в интерфейсе веб-клиента.

## 📁 Структура проекта

```
src/
├── components/
│   ├── AuthModal.tsx         # Экран входа с валидацией инстанса
│   ├── ChatArea.tsx          # Окно сообщений, пузыри чата и поле ввода
│   ├── EmptyChatState.tsx    # Заглушка при отсутствии выбранного диалога
│   ├── NewChatModal.tsx      # Модальное окно создания чата и поиска по номеру
│   ├── SettingsModal.tsx     # Просмотр статуса инстанса и управление сессией
│   └── Sidebar.tsx           # Боковая панель со списком чатов и поиском
├── hooks/
│   └── useNotificationPolling.ts # Хук получения и удаления уведомлений по HTTP API
├── services/
│   └── greenApi.ts           # Сервис взаимодействия с REST API GREEN-API
├── types/
│   └── index.ts              # TypeScript-типы сообщений, чатов и инстанса
├── utils/
│   ├── format.ts             # Форматирование дат, номеров телефонов и аватарок
│   └── sound.ts              # Звуковой сигнал на Web Audio API
├── App.tsx                   # Главный компонент и хранилище состояния
├── index.css                 # Стили Tailwind CSS и дизайн чата
└── main.tsx                  # Точка входа React
```

## 🌐 Деплой в Интернет

Приложение является полностью статическим SPA (Single Page Application) без необходимости отдельного бэкенда:
- Запросы к GREEN-API поддерживают **CORS** (`Access-Control-Allow-Origin: *`).
- Для публикации достаточно залить проект на **Vercel**, **Netlify** или **GitHub Pages**:
  - `Build Command`: `npm run build`
  - `Output Directory`: `dist`
